Boarding

Install it in three moves.

  1. 01
    Close EffectCraft.

    The Window menu is rebuilt at launch.

  2. 02
    Drop the panel in.

    Run the installer, or copy KitFX.jsx into the ScriptUI Panels folder.

  3. 03
    Open Window ▸ KitFX.jsx.

    Dock it, float it, tab it — it behaves like any other panel.

PowerShell 
$panels = "$env:APPDATA\EffectCraft\Scripts\ScriptUI Panels"
New-Item -ItemType Directory -Path $panels -Force | Out-Null
Copy-Item .\KitFX.jsx $panels -Force

Reading .srt files from disk? Keep them beside the project or enable Settings ▸ Scripting & Expressions → Allow scripts to read files.
